# browser-media-sniffer

## 🎉 MediaSniffer v1.2.0 - 网页全媒体智能嗅探与抓取利器

MediaSniffer 是一款基于 Chrome Extension Manifest V3 规范构建的现代化媒体嗅探与下载扩展，支持全页深度扫描、鼠标点选区域抓取、音频提取、视频与直播流画面测活以及一键批量打包下载。

### 🌟 Highlights / 核心亮点
* 🎯 **鼠标交互选区抓取**：悬停即时高亮任意 DOM 容器，按 `↑` / `↓` 扩展或缩小层级，精准提取目标区域媒体。
* 📡 **直播流深度嗅探与播放**：支持 `.m3u8`、`.flv`、`.mpd` 等流媒体抓取，内置 HLS.js 在线播放器与 PotPlayer 外部唤起。
* 🛡️ **无头画面测活引擎**：自动对视频与直播流进行首帧解码探测，智能过滤黑屏/纯音频占位/失效流（可一键切换开关）。
* 🎵 **全格式音频抓取**：支持提取 `.mp3`、`.m4a`、`.flac`、`.wav`、`.ogg` 等背景音乐与音频播客，配有专属动态音波卡片与试听组件。
* 🎛️ **现代毛玻璃控制台 (MediaSniffer Hub)**：支持网格/大图/列表表格四种视图，提供分辨率、宽高比、格式标签等多维度过滤。
* 📦 **多样化导出与打包**：内置 JSZip 批量打包为 `.zip`，支持导出 TXT / JSON / CSV / M3U 播放列表。

### 📦 安装方式
下载 Source Code 解压后，在 Chrome / Edge 扩展管理页面 (`chrome://extensions/`) 打开「开发者模式」，点击「加载已解压的扩展程序」选择该目录即可。
